# VideoMind-Agent v0.7.4 - Competition Demo Release

AI 视频理解与双语字幕智能工作台。

## Quick Start

Download `VideoMind-Agent-v0.7.4-Competition-Demo.zip`, extract it, then run `prepare_videomind_demo.bat` once and double-click `start_videomind.bat`.

## Competition Demo Mode

No DeepSeek API Key is required for the preloaded demo workspace. Preloaded results are clearly identified and are not presented as live AI calls.

## Full AI Processing

Provide your own DeepSeek API Key and the project Whisper environment (`openai-whisper==20250625` in the validated setup) to process new videos. Transcript Correction, Translation, Summary and Q&A currently use the DeepSeek cloud API; the product is not fully offline.

## Demo Features

- Bilingual subtitles
- Subtitle Editor and SRT Export
- AI Video Summary
- Grounded Video Q&A
- Timestamp Seek
- Custom subtitle player
- Fullscreen subtitles

## Platform

Windows 10 / 11. Python 3.11, Node.js/npm and FFmpeg/ffprobe are prerequisites. This package is a Competition Demo / Prototype, not a self-contained installer.
